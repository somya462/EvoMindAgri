⌁
IMPLEMENTED GOVERNANCE PILLARS

How EvoMindAgri protects memory integrity

  • Symbolic Assertion FilteringBlocks hypothetical queries, general agronomy questions, and third-party neighbor mentions before memory proposals are created.
  • Quarantined HITL Approval GateExtracted entities remain isolated in a pending queue and are never injected into LLM context until explicitly approved by the farmer.
  • Provenance & Version ArchivalUpdates to evolving attributes (such as soil pH or irrigation method) preserve prior snapshots in memory_versions alongside an audit log.
  • Temporal Validity & Safety GuardrailsEnforces validity windows and soil-chemistry constraints (e.g., elemental sulfur vs. agricultural lime) during response generation.
SYSTEM PIPELINE & EVALUATION

Current Build Capabilities

This implementation integrates a deterministic spaCy EntityRuler agricultural NLU pipeline, a MongoDB versioned memory store, and local inference via Ollama (Qwen2.5:3B).

Empirical Benchmark: Evaluated across multi-turn recall, temporal update, context-poisoning trap, and safety scenarios against stateless and un-gated auto-memory baselines.
